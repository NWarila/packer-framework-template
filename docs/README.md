# Documentation

This repo follows the Diataxis documentation layout:

- `tutorials/` - step-by-step guides for new framework maintainers. Start with [Derive your first Packer framework](tutorials/derive-your-first-packer-framework.md).
- `how-to/` - operational tasks for maintaining the template.
- `reference/` - command surface, invariants, mirroring, and release gates.
- `explanation/` - architecture, testing strategy, and threat model.
- `decision-records/` - org, template, and repo ADRs.
- `diagrams/` - Mermaid source diagrams. See [architecture.mmd](diagrams/architecture.mmd) for the system context view.

The reference Packer framework lives under [`../packer/`](../packer/), with example framework inputs under [`../examples/`](../examples/).
